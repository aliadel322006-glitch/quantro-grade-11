Variables & Data Types

In programming, variables are like containers used to store data values. Think of them as labeled boxes where you can keep information that your program will need later.

data_object

lightbulb Core Concept

Python is dynamically typed. This means you don't have to explicitly declare the type of a variable when you create one. Python figures it out based on the value you assign to it.

int Integer (whole numbers like 42 or -7)
str String (text data like "Hello World")

Naming Conventions

  • Variable names must start with a letter or underscore _.
  • They can contain letters, numbers, and underscores.
  • Python conventions suggest using snake_case for variable names.
terminal main.py 
# Define a string variable
student_name = "Alice"

# Define an integer variable
student_age = 16

# Define a boolean variable
is_enrolled = True

# Let's print them out and check their types
print("Name:", student_name, type(student_name))
print("Age:", student_age, type(student_age))
print("Enrolled:", is_enrolled, type(is_enrolled))
TERMINAL
$ python main.py
Name: Alice <class 'str'>
Age: 16 <class 'int'>
Enrolled: True <class 'bool'>
