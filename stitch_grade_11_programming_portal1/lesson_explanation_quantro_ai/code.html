مقدمة في المتغيرات (Variables)

تعلم كيفية تخزين البيانات واسترجاعها في لغة بايثون.

info

مفهوم المتغيرات

تخيل المتغير كصندوق يمكنك وضع أشياء فيه لتخزينها واستخدامها لاحقاً. في البرمجة، المتغير هو مساحة في الذاكرة نخصصها لتخزين قيمة معينة (مثل رقم، نص، أو قائمة). نعطي هذا الصندوق اسماً لنتمكن من الرجوع إليه عند الحاجة.

نقاط رئيسية

  • check_circle الاسم يجب أن يبدأ بحرف أو شرطة سفلية (_).
  • check_circle بايثون حساسة لحالة الأحرف (A يختلف عن a).
  • cancel لا يمكن استخدام الكلمات المحجوزة (مثل if, for).
code

أمثلة برمجية


# تعريف متغير نصي (String)
student_name = "أحمد"

# تعريف متغير رقمي صحيح (Integer)
age = 16

# طباعة المتغيرات
print("الاسم:", student_name)
print("العمر:", age)

مخرجات الكود:

الاسم: أحمد
العمر: 16

auto_awesome

تلميح ذكي

في بايثون، لست مضطراً لتحديد نوع المتغير (مثل int أو string) عند تعريفه. اللغة تكتشف النوع تلقائياً بناءً على القيمة التي تسندها إليه. هذا يسمى "التشخيص الديناميكي" (Dynamic Typing).
